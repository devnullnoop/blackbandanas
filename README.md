# blackbandanas.com

Landing page for Black Bandanas.

Single static HTML file, no build step. Hosted on GitHub Pages, deployed from `main` branch at root.

## Local preview

Open `index.html` directly in a browser, or run a simple static server:

    python3 -m http.server 8000

Then visit `http://localhost:8000`.

## Deploying

Any push to `main` publishes to the live site within a minute.
